## 1. 프로젝트 개요

### 1.1 배경
㈜루다시스템즈는 공공기관 및 민간기업 대상 SI/SM, 솔루션 개발, UI/UX 개발, AI·블록체인, Local LLM 구축을 수행하는 IT 전문 기업이다. 국회 e-의안시스템, 관세청 솔루션 검증, 국회 입안지원 시스템 등 다수의 공공 프로젝트 수행 이력을 보유하고 있으나, 이를 외부에 전문적으로 표현할 공식 홈페이지가 부재하다. 본 프로젝트는 기업의 브랜드 가치와 기술 전문성을 효과적으로 전달하는 프리미엄 기업 홈페이지를 구축하는 것을 목표로 한다.

### 1.2 핵심 브랜드 메시지
> **"Think And Act, In an Independent Way."**
> 독립적인 사고와 실행력을 기반으로 공공·기업 IT 혁신을 선도하는 전문 IT 솔루션 기업

## 2. 목표 (Goals)

### 2.1 비즈니스 목표
1. IT 전문기업으로서의 브랜드 이미지 강화
2. 공공기관·기업 고객 대상 신뢰 확보
3. SI / 솔루션 / 시스템 구축 역량 홍보
4. 프로젝트 수행 경험과 기술력의 효과적 표현
5. 신규 사업 문의 및 협업 문의 확보 (리드 창출)

### 2.2 성공 지표 (KPI)
| 지표 | 목표 |
|------|------|
| 사업 문의 전환 | 월 5건 이상 Contact Form 제출 |
| 회사소개서 다운로드 | 월 30건 이상 |
| 평균 체류 시간 | 1분 30초 이상 |
| 모바일 사용성 점수 | Lighthouse 90점 이상 |
| 검색 노출 | "SI 개발 전문기업", "공공 시스템 구축" 키워드 2페이지 내 |

### 2.3 Non-Goals (이번 범위 제외)
- 다국어(영문) 페이지 — 1차 한국어 우선, 추후 확장
- 회원가입/로그인 기반 커뮤니티
- 전자상거래/결제 기능
- 실시간 채팅 상담 (추후 도입 검토)

## 3. 타겟 사용자 (Target Persona)

| 페르소나 | 설명 | 핵심 니즈 |
|----------|------|-----------|
| 공공기관 정보화 담당자 | 사업 발주 전 수행사 역량 검증 | 공공 수행 실적, 기술 신뢰도, 회사 안정성 |
| 대기업 IT 구매/제휴 담당자 | 협력사·외주 후보 탐색 | 사업영역, 기술 스택, 레퍼런스 |
| 잠재 협력사 | 컨소시엄·협업 파트너 검토 | 전문 분야, 연락처, 조직 규모 |

## 4. 디자인 방향성

### 4.1 컨셉
"신뢰 + 기술력 + 혁신 + 전문성" — 글로벌 IT 기업 / B2B SaaS 스타일의 깔끔하고 미래지향적인 분위기. 참고 벤치마크: 삼성SDS, LG CNS, 네이버클라우드 등 글로벌 SI 기업 홈페이지.

### 4.2 컬러 시스템
첨부 이미지(딥 네이비 + 시안/테크 블루 + 화이트) 기반의 테크·미래형 팔레트를 적용한다. 상세 토큰은 TRD 디자인 토큰 섹션 참조.

| 역할 | 컬러 | 용도 |
|------|------|------|
| Primary (Deep Navy) | `#0B1B2B` ~ `#111827` | 헤더, 다크 섹션 배경 |
| Accent (Tech Cyan) | `#17B8C4` / `#22D3EE` | 강조, CTA, 하이라이트 |
| Base (White) | `#FFFFFF` | 밝은 섹션 배경 |
| Text | `#191F28` / `#6B7684` | 본문/보조 텍스트 |

### 4.3 무드
Hero 및 주요 섹션에 AI / Cloud / Data / Network를 연상시키는 미래형 그래픽·모션을 적용한다.

## 6. 페이지별 기능 요구사항

### 6.1 Main (메인)
- **Hero Section**
  - 메인 카피: "Think And Act, In an Independent Way."
  - 서브 문구: "독립적인 사고와 실행력을 기반으로 공공·기업 IT 혁신을 선도하는 전문 IT 솔루션 기업"

- 하위 섹션: 핵심 사업영역 요약(카드), 대표 수행 프로젝트 하이라이트, 기술역량 요약, 최신 소식(News), Contact CTA 밴드

- **기업개요**: 회사 기본 정보(표 3.3) + 소개 문단
- **Vision**: "Independent Thinking, Smart Technology, Reliable Solution" 3대 가치 카드
- **조직구성**: 조직도 UI (카드형)
  ```
  CEO
  ├ R&D 연구소

  ├ UI/UX 개발팀
  └ 경영지원부
  ```

기술 스택 아이콘으로 표현: **Frontend / Backend / Database / Cloud / System Integration / UI/UX**. 각 영역별 보유 기술 태그(예: React·Next.js, Java/Spring, Oracle·PostgreSQL, AWS, 연계·이관, Figma 등).

### 6.6 Contact (문의)
- 회사 위치(지도), 이메일, 전화번호

## 7. 공통/부가 기능

### 7.1 반응형
Desktop / Tablet / Mobile 3종 필수 대응. 지원 브라우저: Chrome, Edge, Safari (최신 2개 버전).

### 7.2 관리자(CMS)
관리자 화면에서 다음 관리 가능:
- 프로젝트 등록/수정/삭제
- 회사소개 내용 수정
- 뉴스(소식) 등록
- 문의 내역 조회/상태 관리

### 7.3 SEO
- Meta Tag, Open Graph, Sitemap(`sitemap.xml`), `robots.txt`
- 타겟 키워드: "IT 솔루션 기업", "SI 개발 전문기업", "공공 시스템 구축", "웹 시스템 개발"

### 7.4 접근성
WCAG 2.1 AA 준수 지향 (명도 대비, 키보드 내비게이션, 대체 텍스트).
